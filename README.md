# Flood-Detection-using-YOLOv11
A computer vision project for flood detection using YOLOv11, trained and tested with a Roboflow dataset.
## Project Overview

This project detects flood-related images using YOLOv11.
The model was trained and tested using a Roboflow dataset.

## Model Performance

- Model: YOLOv11 Nano
- mAP@50: 89.8%
- Precision: 70.1%
- Recall: 100%
- F1 Score: 82.4%

## Roboflow Project

[View Flood Detection Project](https://app.roboflow.com/arigela-pavani/flood-detection-oh5pi/visualize/1)

## Testing

The trained model was tested on flood-related images and successfully detected flood-related content.
